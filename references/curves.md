# Curves — 曲线为什么最难，怎么办

## 用户 2026-11-03 的原话问题

T 恤 v1 的袖山弧线不像。用户问：AI 画版最难的是不是画曲线？

答案是：是。直线只要两个点，曲线有无穷多种画法：同一个起点终点、同一个长度，可以画出无数条长得完全不同的弧。只给大模型“画一条袖山弧线”，它没有任何办法同时保证下面四件事：

1. 形状像（穹顶、不是屋顶）
2. 切线对（顶端水平、腋下收角）
3. 长度对（袖山 = 前后袖窿 + 容量）
4. 能裁、能缝（缝份偏移后不变形）

v1 恰恰就栽在第 2 条上：袖山是两段二次贝塞尔在顶端相交，两段在顶端的切线都不水平，拼出来就是一个尖顶。

## 本仓的曲线规矩（v2 起）

曲线不许由 agent 手写坐标、也不许由大模型“凭感觉”画。必须走下面这条链：

1. **制版点先行。** 先定一串有制版意义的点：腋下点、袖山中段点、袖山顶点。v2 袖山是 9 个点：腋下、8%/82%、20%/48%、34%/20%、顶点、66%/20%、80%/48%、92%/82%、腋下（百分比是相对袖宽 / 袖山高）。
2. **样条过点，切线连续。** 用 Catmull-Rom 转三次贝塞尔，相邻两段在共享点切线相同，不出尖、不出折。顶点两侧的点等高，所以顶点切线严格水平，画出来是穹顶。
3. **长度最后拟合。** 曲线形状定死后，再二分法调袖片腋下宽，让袖山长 = 前后袖窿长 + 容量（v2：43.4 + 1.5 = 44.9 cm）。形状和长度分开管，不许为了凑长度把形状拉变形。
4. **缝份是偏移，不是缩放。** 缝份线是把净样曲线上的采样点沿法线外移 1 cm（v2 袖片橙色虚线就是这么画的，和用户 CAD 里黄线净样 + 橙线缝份的双线是一个做法）。把整条曲线放大 1 cm 会改长度、改形状，是错的。

## 还没解决的

- **前后不对称。** 真袖山前片平、后片满，顶点偏后，还有前后剪口区分。v2 是对称基础款，没冒充前后片分开的袖山。
- **参考曲线拟合。** 最像的办法不是发明点，而是拿一条已经验证过的袖山（比如用户 CAD 里那条）当模板：导出它的 DXF/SVG，采样它的袖山点，按袖窿长度等比缩放，再跑第 3 步的长度拟合。下一版要做这个时，需要用户给那条袖山的 DXF 或它的袖山高 / 袖窿长。
- **袖窿、领窝同理。** 领窝、袖窿、裤裆弯、驳头弧线全部适用同一条规矩：点 + 切线 + 长度 + 法线偏移，缺一不可。
